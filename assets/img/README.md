# Photography drop-in guide

The site is designed so photos slot straight in — add files with these exact
names and they appear automatically (no code changes needed). Until a file
exists, the site shows an elegant branded placeholder instead.

| File | Where it appears | Suggested shot |
| --- | --- | --- |
| `hero.jpg` | Full-screen hero background (dark overlay is applied for legibility) | Wide interior of the hall — the roof-truss shot works beautifully |
| `building.jpg` | "The old market, reborn" section (portrait crop, 3:3.6) | Arched windows / brickwork detail |
| `market-hall.jpg` | Market Hall card (16:10 landscape) | Market hall interior |
| `food-hall.jpg` | Food Hall card (16:10 landscape) | Food hall / counters |
| `team/andy-johnson.jpg` | Team card (portrait, ~4:4.7) | Head-and-shoulders portrait |
| `team/jay-jacoby.jpg` | Team card | Head-and-shoulders portrait |
| `team/tommy-tannock.jpg` | Team card | Head-and-shoulders portrait |
| `team/mark-oconnell.jpg` | Team card | Head-and-shoulders portrait |

Tips:

- Aim for JPGs around 1600–2400px on the long edge, ~200–500KB each
  (export at quality 70–80). The hero can be up to ~3000px wide.
- Portraits work best with a little headroom — the crops centre on the
  middle of the frame.
